# Z 2 Digital — Private Preview

## Deploy on Render Free

This repository includes a Render Blueprint in `render.yaml` configured for a **Free Node web service**. It does not request a paid instance or persistent disk.

1. In Render, choose **New → Blueprint**.
2. Connect `zaminsahab03000964560-source/zamin-ai-outreach` and select branch `z-to-digital-rebrand`.
3. Review the Blueprint. Confirm the service plan is **Free** and no paid disk is being added.
4. Set the private environment variables:
   - `OWNER_PASSWORD`: choose a unique password of at least 12 characters.
   - `OPENAI_API_KEY`: add your private OpenAI API key to enable the Central AI Assistant.
   - `SESSION_SECRET` and `WORKSPACE_ADMIN_TOKEN` are generated by the Blueprint.
   - `VAPI_API_KEY` is optional unless voice assistant administration is needed.
5. Deploy. Render will provide a service URL after a successful deployment.

## Free-plan storage limitation

The Free service has no persistent disk. Task records are stored in the service's local SQLite file and may be lost when the free service restarts, redeploys, or its filesystem is replaced. Do not use this preview as the only copy of important business records. Persistent storage requires a separate database or a paid persistent disk.

## Private preview and safety

The owner login gate is enabled. Keep the preview URL private. Verify owner login, logout, task saving, and AI chat before wider use.

The current app can prepare AI plans and drafts. It does not send marketing emails, publish campaigns, or modify external CRM records. Those integrations must be connected and explicitly approved separately.

## Local development

Requires Node.js 20 or newer.

```sh
npm install
cp .env.example .env
# Set OWNER_PASSWORD (12+ chars), SESSION_SECRET (32+ chars), and OPENAI_API_KEY in .env
npm start
```

Open http://localhost:3000.
