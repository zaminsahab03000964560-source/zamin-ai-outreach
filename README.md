# Z 2 Digital — Private Preview

## Deploy on Render

This repository includes a Render Blueprint in `render.yaml`.

1. Push the `z-to-digital-rebrand` branch to GitHub.
2. Sign in to Render and choose **New → Blueprint**.
3. Connect this repository and select branch `z-to-digital-rebrand`.
4. Review the Blueprint. It creates a Node web service and a 1 GB persistent disk mounted at `/var/data`.
5. Before the first deploy, set the secret environment variables in Render:
   - `OWNER_PASSWORD`: choose a unique password of at least 12 characters.
   - `OPENAI_API_KEY`: add the private OpenAI API key.
   - `SESSION_SECRET` and `WORKSPACE_ADMIN_TOKEN` are generated by the Blueprint.
   - `VAPI_API_KEY` is optional until voice-assistant administration is configured.
6. Deploy. Render will provide a service URL after the first successful deployment.

The app uses `/var/data/z2digital.sqlite` so task records persist on the attached disk. The disk requires a paid Render web-service plan; do not remove it if you need database persistence.

## Private preview and publishing

The owner login gate is enabled in the dashboard. Do not share the preview URL publicly. Verify owner login, logout, task saving, database persistence after a restart, and AI chat before any public launch.

The current app does not send marketing emails, publish campaigns, or modify external CRM records. Those integrations must be connected and explicitly approved separately.

## Local development

Requires Node.js 20 or newer.

```sh
npm install
cp .env.example .env
# Set OWNER_PASSWORD (12+ chars), SESSION_SECRET (32+ chars), and OPENAI_API_KEY in .env
npm start
```

Open http://localhost:3000.
